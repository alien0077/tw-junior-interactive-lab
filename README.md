# 台灣國中互動探究實驗室 v2.0（108 課綱全科 43 單元）

> **線上立即體驗（GitHub Pages）**：https://alien0077.github.io/tw-junior-interactive-lab/

融合 **均一教育平台微概念鷹架**、**LIS 科學史實驗反例**、**PhET 雙視角動態操控** 與 **台灣 108 課綱素養會考破題** 的零選擇題互動式網頁學習平台。

## 涵蓋範圍（100% 完整上線）
- **📐 數學科（18 單元）**：七～九年級全單元，涵蓋負數數線、天平一元一次方程式、乘法公式面積拼圖、畢氏定理水車、二次函數拋物線、圓的性質、三心與盒狀圖等。
- **🔬 自然科（16 單元）**：生物、理化、地科全單元，涵蓋滲透膨壓、酵素變性、循環系統、阿基米德浮力溢水秤、透鏡成像、化學限量試劑、電路電子能量背包、板塊造山與四季潮汐等。
- **🌍 社會科（9 單元）**：地理、歷史、公民與九年級跨科統整，涵蓋台灣地形焚風、手搖飲供需動點 vs 移線、大航海台灣史、東亞白銀網、近代世界因果骨牌、法律分流與五權制衡等。

## 每單元五階段教學循環（含完整題型講義）
1. **① 衝突提問（Engage）**：拋出直覺陷阱，引發認知衝突。
2. **② 雙視角互動操控（Explore）**：HTML5 Canvas 即時動態視覺化實驗室。
3. **③ 原理與常見疑問詳解（Explain）**：白話講透「為什麼」，破解高頻卡關疑問。
4. **④ 迷思反例與會考拆題（Evaluate & Tactics）**：含兩層漸進提示抽屜、題幹關鍵字雷達、步驟積木槽與迷思診斷 JSON 追蹤儀表板。
5. **⑤ 完整講義與各類題型全攻略（Handbook）**：全科 43 單元共整理 **264 大常見題型與逐步解法**、**209 步審題決策流程**、**195 則考場常見錯誤（❌ 錯 vs ✅ 正確）**與 **264 題附詳解互動練習題**，支援一鍵列印紙本講義。
